# repo_Trenzas

## Las 24 trenzas del Sitio Abismal

Este repositorio reúne exploraciones realizadas a partir de las **24 trenzas del Sitio Abismal**, desarrolladas en el proyecto Vestibles — TTT, Textiles, Técnicas y Tecnologías (2023), y relacionadas con el proyecto TTT2 — La Piel Tejida: Codificar y Significar mediante una proto-Escritura (2025).

La **trenza** aparece aquí desde una idea sencilla de lo textil: varias hebras que se relacionan y se entrelazan para formar una nueva estructura.

La exploración busca observar qué ocurre cuando esta idea se lleva a un recorrido que puede cambiar y desviarse.

Se trabajan principalmente cuatro condiciones:

- **Contención:** define y guía los límites del recorrido.
- **Ruido:** introduce pequeñas desviaciones.
- **Entropía:** permite que esas desviaciones se acumulen durante el recorrido.
- **Torsión:** hace que las trayectorias puedan entrelazarse.

De esta manera:

```text
CONTENCIÓN
     +
   RUIDO
     +
 ACUMULACIÓN
     +
  TORSIÓN
     ↓
  RECORRIDO
     ↓
   TRENZA
   ```
   
   La trenza no se dibuja directamente. Se observa cómo puede aparecer a partir de un recorrido, sus desviaciones, sus límites y su entrelazamiento.

El repositorio reúne distintas pruebas para explorar estas relaciones y avanzar posteriormente hacia el diccionario de operaciones de TTT2.
